Output Device
Switch the system default output. Add several devices to cycle through them in order — each press selects the next. Give each device an icon to show which output is active.
Icons are optional: with none set here, and "Cycle" below, the key keeps the image you chose in OpenDeck. The first icon set here — per device, when inactive, or the greyed-out look of "Disable" — hands the key image over to the plugin, and OpenDeck's own image is gone for good.
