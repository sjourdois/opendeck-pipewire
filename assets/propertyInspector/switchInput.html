Input Device
Switch the system default input. Add several devices to cycle through them in order — each press selects the next. Give each device an icon to show which input is active, and a name of your own to show instead of the device's.
Icons are optional: with none set here, the key keeps the image you chose in OpenDeck. The first icon set here hands the key image over to the plugin, and OpenDeck's own image is gone for good.
